# Portfolio

Personal portfolio website for **Arsh Verma** — showcasing projects, experience, research, and live coding stats.

**Live:** [arsh-verma.vercel.app](https://arsh-verma.vercel.app)

## Tech Stack

React · TypeScript · Tailwind CSS · Vite · Express · Framer Motion · Vercel

## Getting Started

```bash
git clone https://github.com/ArshVermaGit/portfolio.git
cd portfolio
npm install
```

Create a `.env` file with your GitHub token:

```
GITHUB_TOKEN=ghp_your_token_here
```

Run the dev server:

```bash
npm run dev
```

## Scripts

| Command              | Description                        |
| -------------------- | ---------------------------------- |
| `npm run dev`        | Start frontend + backend           |
| `npm run build`      | Production build                   |
| `npm test`           | Run unit tests                     |
| `npm run test:e2e`   | Run E2E tests (Playwright)         |
| `npm run lint`       | Lint with ESLint                   |
